# 발표 스크립트

아이폰 12 mini(375 × 812 CSS 픽셀) 기준의 모바일 대본 뷰어입니다. 빌드 없이 `index.html`을 브라우저에서 열면 됩니다.

## 대본 추가

`index.html`에서 `원고 수정`을 검색하세요. 아래 블록을 복사해 기존 대본 section 뒤, footer 앞에 붙여 넣으세요. 목차와 페이지 수는 자동으로 갱신됩니다.

```html
<section class="script-area slide" data-topic="핵심 내용" hidden>
  <h1 class="script-title">전달할 메시지</h1>
  <div class="script-text">
    <p>여기에 읽을 대본을 작성하세요.</p>
    <p><mark>강조할 문장</mark>을 표시할 수 있습니다.</p>
  </div>
</section>
```

- `data-topic`: 목차의 주제 이름. 같은 이름은 자동으로 묶입니다. 생략하면 ‘기타’에 표시됩니다.
- `script-title`: 목차에만 표시할 제목입니다. 발표 본문에서는 숨깁니다.
- `script-text`: 대본 본문입니다. 문단마다 `<p>`를 추가하세요.
- 한 `section`이 한 페이지이며 HTML 작성 순서대로 이동합니다.
- `hidden`: 초기 숨김 속성입니다. 페이지를 선택하면 자동으로 표시됩니다.

현재 입력된 대본은 총 50페이지입니다. `id="slide-01"`부터 `id="slide-50"`까지 원하는 페이지를 찾아 수정하세요. 목차는 발표 소개, 1~5장, 마무리로 묶여 있으며 페이지별 내용 제목과 본문 미리보기가 표시됩니다. 검색은 주제·제목·전체 본문을 대상으로 합니다.

## 사용법

처음에는 목차가 열립니다. 카드를 누르면 해당 대본으로 이동합니다. 상단 ‘목차’로 목록을 열고, 목록에서 다시 누르면 읽던 페이지로 돌아갑니다.

목차의 ‘시작’을 누르면 1페이지와 00:00에서 발표를 시작합니다. 일시정지 후 ‘계속’은 읽던 페이지와 시간에서 이어갑니다. ↺ 버튼은 페이지와 시간을 초기화합니다. 새로고침하거나 다시 열면 첫 페이지가 선택된 목차와 00:00으로 초기화됩니다.

- 본문 화면 왼쪽 절반 터치: 이전 페이지
- 본문 화면 오른쪽 절반 터치: 다음 페이지
- 키보드 방향키도 지원
- 대본은 실제 화면 높이와 분량에 맞춰 글자 크기를 자동 조절해 한 화면에 표시
- 첫 페이지와 마지막 페이지에서 이동 범위 제한

발표 화면에는 대본과 목차 버튼·페이지 수·경과 시간만 표시합니다. 제목·주제·타이머 조작·테마 설정은 목차에서 확인합니다. 본문은 최대 24px에서 시작해 페이지 전체가 화면에 들어가는 크기로 자동 조절합니다. 줄 간격은 1.6배, 좌우 여백은 12px입니다. Safari 주소창 변화, 화면 회전에도 다시 계산합니다. 페이지 수와 경과 시간은 22px 굵은 글자로 상단에 표시하고, 하단 진행률은 2px 선으로 표시합니다.

14분 30초 목표 타이머, 진행률, 종이·세이지·바다 테마, 다크 모드를 유지합니다. 페이지별 글자 수에 비례해 목표 시간을 배분하고, 경과 시간에 따른 적정 페이지와 속도 안내를 색상으로 표시합니다. 목차에서도 실행 중인 타이머는 계속됩니다. 화면 설정은 같은 브라우저에 저장됩니다. 페이지와 타이머 상태는 저장하지 않습니다.

## 발표 기호

현재 본문은 새로 제공된 50페이지 대본을 반영했으며 코드 블록 구분선은 표시하지 않습니다. 필요한 경우 아래 기호를 추가할 수 있습니다. 기호는 소리 내어 읽지 않습니다. 뜻은 목차의 ‘발표 기호 안내’에서도 확인할 수 있습니다.

| 기호 | 의미 |
| --- | --- |
| `/` | 짧게 호흡 |
| `//` | 길게 멈춤 |
| `**단어**` | 강하게 강조 |
| `↑` | 억양 올리기 |
| `↓` | 억양 내리기 |
| `[천천히]` | 속도 낮추기 |
| `[또렷하게]` | 발음 강조 |
| `[미소]` | 부드러운 표정과 어조 |

색상 표시는 `<span class="speech-cue">/</span>`, 강조 표시는 `<strong class="speech-emphasis">**핵심 단어**</strong>`처럼 작성합니다. 일반 HTML이므로 `**`만 입력하면 자동으로 굵게 변환되지는 않습니다.

## 배포

`index.html`을 GitHub Pages 등 정적 호스팅에 올리면 됩니다. 별도의 서버나 빌드가 필요하지 않습니다.
