# Deployment

- Deploy this project to GitHub Pages at https://ohddang.github.io/script/.
- The source repository is https://github.com/ohddang/script.git. Publish by committing the final root `index.html` and pushing `main` to `origin`, then verify the GitHub Pages deployment.
- Do not deploy this project with the Sites plugin or to a `chatgpt.site` address unless the user explicitly requests it. Existing `.openai/` and `.site-publish/` files are legacy artifacts, not the deployment target.
- Preserve the user's latest script edits when preparing a deployment.
